## 🔧 UX fixes da sessão

- **Hover sem barra dourada lateral**: removido `box-shadow: inset 3px 0 0 var(--ouro)` que criava "moldura" nas divisões de coluna (parecia que CPF estava destacada). Agora só escurece o fundo (#DBCDB7) com transition suave.
- **Scroll horizontal em Funcionários+Cargos**: classe `.table-wrap-x` opt-in (default é `overflow-x: clip` pra preservar sticky thead globalmente)
- **Barra de rolagem espelhada acima da tabela**: helper `setupTopScrollFor(wrapEl)` cria div fina com width = `table.scrollWidth` e sync bidirecional via `scroll` events. Scrollbar nativa do wrap escondida (`scrollbar-width: none` + `::-webkit-scrollbar{display:none}`). Renderizado após cada `renderXxx()` e em `window.resize`.
- **Sticky thead desligado dentro de `.table-wrap-x`**: quando o wrap vira contexto de scroll, o `position: sticky` se grudava ao wrap e o cabeçalho rolava junto com a página. Agora `thead th { position: static }` só dentro de `.table-wrap-x`; sticky continua funcionando em todas as outras tabelas.

## 📐 Responsividade universal (commit 97ab6a8 — adicionado após o handoff)

Juliana reportou que o sistema ficou "desproporcional em outros computadores". Diagnóstico:
- `.main` tinha `padding: 24px 32px` fixo, sem `max-width` → estourava em telas pequenas e estirava feio em monitores grandes
- Fonte raiz hardcoded em `15px` → muito grande em notebooks 13", muito pequena em 4K
- Só 4 media queries (880, 640, 1280) — sem cobertura pra 1024 nem 1440

Fixes aplicados em `styles.css`:
1. Variáveis `--main-max-w` (1600px) e `--main-pad-x` (clamp 14-40px fluido)
2. `html { font-size: clamp(13.5px, 0.35vw + 12.5px, 16px) }` — escala suave entre viewports 1280-1920px
3. `.main { max-width: var(--main-max-w); margin: 0 auto }` — centraliza em monitores grandes
4. **Breakpoint 1366px**: sidebar 230 → 200, padding e KPIs mais compactos (notebooks padrão)
5. **Breakpoint 1024px**: sidebar vira só ícones, KPIs em auto-fit, subtítulo da topbar some
6. **Breakpoint 768px** (mobile): sidebar drawer com transform, main 100%, KPIs 2 colunas, toolbar empilhada
7. **Breakpoint 1920px+**: `--main-max-w` sobe pra 1720px mas não infinito (evita "deserto" em ultrawide)
8. `min-width: 0` reforçado em `app-shell`, `layout`, `main`, `card`, `fat-card`, `tabela`
