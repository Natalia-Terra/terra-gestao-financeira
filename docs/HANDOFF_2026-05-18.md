### 2. M28b — Fix NUCLEAR dos 2 bugs (commit `ab66bcd`)

**Modal de Editar (e todos os modais genéricos):** `abrirModal` agora força
visibilidade via `setProperty(..., 'important')` em 8 propriedades CSS
(display, visibility, opacity, pointer-events, z-index 99999, position fixed,
top/left/right/bottom 0). Também move o overlay direto pro `<body>` se não
estiver lá — escapa de qualquer container ancestral com `overflow:hidden`.

**Reset Completo:** removido o input de confirmação. Botão "Executar Reset
Completo" agora dispara um `prompt()` nativo do browser pedindo "digite
RESET". Como o prompt é do navegador (fora do DOM da app), nada da página
consegue interceptá-lo — header fixo, overlay órfão, nada.
